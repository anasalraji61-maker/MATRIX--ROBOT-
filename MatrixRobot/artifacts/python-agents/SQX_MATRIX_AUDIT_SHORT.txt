■ الحقيقة في سطر واحد
  SQX لا يقرأ كود Python — لكنه يختبر «محرك الإشارة» الذي وصفناه في المواصفات.
  الفرق بين نتيجة SQX ونتيجة Matrix backtest = اقتراحات التعديل على الروبوت.

================================================================================
المرحلة 1 — عكس Matrix داخل SQX (أنت الآن هنا)
================================================================================

في SQX: Builder → Full settings → مشروع جديد اسمه Matrix_Audit

[A] البيانات (Data Manager أولاً إن لزم)
    EURUSD, GBPUSD, USDJPY, USDCAD
    الأطر: M15, H1, H4
    فترة: 2015–2024 على الأقل

[B] Build settings — قيود مطابقة لـ Matrix
    • نوع: Multi-symbol + Multi-timeframe
    • SL/TP: ATR-based أو fixed pips مع Min RR ≥ 1.5
    • Risk: 0.8% per trade (مثل max_risk_per_trade_pct)
    • Max positions: 7
    • Session filter: London + NY (07–17 UTC تقريباً) إن وُجد

[C] Building blocks — فقط ما يستخدمه Matrix ensemble:
    ✓ EMA (20/50/200)
    ✓ RSI
    ✓ MACD
    ✓ ADX
    ✓ ATR (للستوب)
    ✗ لا تفعّل كل الـ 117 block عشوائياً — قلّل للمنطق أعلاه

[D] Cross checks (فعّل قبل Start):
    ✓ Higher precision
    ✓ Walk-Forward أو OOS
    ✓ Monte Carlo (إن متاح في Trial)

[E] Start → انتظر databank full

================================================================================
المرحلة 2 — ماذا «يقترح» SQX؟ (ترجمة للروبوت)
================================================================================

بعد البناء، من أفضل 5 استراتيجيات في Results سجّل:

  | ما يظهر في SQX          | ماذا نغيّر في Matrix (.env / config)     |
  |-------------------------|------------------------------------------|
  | RR الأفضل ≈ 2.0         | normal_trade_require_rr_min              |
  | فلتر جلسة London فقط    | SESSION_FILTER_MODE, killzone rules      |
  | SL = 1.5×ATR            | risk_sizing / scalping SL pips           |
  | لا صفقات M15 ضعيفة      | SCALPING_MIN_STRENGTH ↑                  |
  | PF عالٍ بدون Stoch      | تخفيض وزن stoch في ensemble (لاحقاً)    |
  | الاستراتيجية تنهار 4×   | SYMBOL_QUARANTINE أو إزالة زوج           |

SQX يقترح على مستوى القواعد — نحن نطبّق على Council/Risk/Execution.

================================================================================
المرحلة 3 — مقارنة مع Matrix (تشخيص السائق)
================================================================================

على VPS — لكل زوج (EURUSD, GBPUSD, USDJPY, USDCAD) H1:
  POST /agents/backtest/run  أو RUN_BACKTEST_*.bat

جدول المقارنة:

  | الزوج   | SQX PF | Matrix backtest PF | الفرق |
  |---------|--------|-------------------|-------|
  | EURUSD  |        |                   |       |
  | GBPUSD  |        |                   |       |
  | ...     |        |                   |       |

قرار:
  • SQX عالٍ + Matrix منخفض  → أصلح السائق (Risk, Session, Scalp, GPT)
  • كلاهما منخفض           → أصلح المحرك (قواعد ensemble — من SQX)
  • SQX منخفض على Retest    → لا تدمج — ابحث من جديد
