■ ما أنجزناه محلياً
────────────────────────────────────────────────────────────────────────────
  • MATRIX_FOR_QC_PREP.txt     — خطة الطبقات والمراحل
  • quantconnect/MatrixRobotQC/main.py — هيكل خوارزمية QC (مرحلة 0)
  • matrix_layers/             — سيُملأ عند port المرحلة 1

■ ما تحتاجه أنت (مرة واحدة)
────────────────────────────────────────────────────────────────────────────

  1) حساب QuantConnect (موجود عندك)

  2) إنشاء مشروع
     • Algorithm Lab → New Algorithm → Python
     • أو اسم المشروع: MatrixRobotQC

  3) رفع الكود
     • انسخ محتوى main.py إلى المحرر
     • أو استخدم Lean CLI:
         lean cloud push --project "MatrixRobotQC"

  4) Lean CLI (اختياري — للتطوير المحلي)
     • تثبيت: pip install lean
     • lean login
     • User ID + API Token من: quantconnect.com → Account → Security

  5) تشغيل Backtest
     • من واجهة QC: Backtest
     • اختر فترة الاختبار بنفسك في الإعدادات
     • راجع Logs و Statistics

■ ما لا ترفعه أبداً إلى QuantConnect
────────────────────────────────────────────────────────────────────────────
  • ملف .env من VPS
  • مفاتيح API (Twelve Data, OpenRouter, MT5, Telegram)
  • كلمات مرور الوسيط

■ ما يفحصه QC بعد اكتمال الـ port
────────────────────────────────────────────────────────────────────────────
  • منطق الإشارة (ensemble + ICT)
  • المجلس (council) — من يوافق / يرفض
  • المخاطرة (risk) — قواعد الحجم والحدود
  • المحفظة متعددة الرموز
  • مقترحات تحسين — أنت تطبّقها في Matrix
